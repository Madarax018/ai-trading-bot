# AI Trading Bot

Educational paper trading simulator.

Run: python main.py

No real-money orders or broker API connections.

## Installation

Clone the repository:

```bash
git clone https://github.com/Madarax018/ai-trading-bot.git
cd ai-trading-bot
```

## Running the project

Run `python main.py`.

## Automated testing

Run the tests locally:

```bash
python -m unittest discover -s tests -v
```

GitHub Actions runs these tests automatically when
changes are pushed or a pull request is opened.
